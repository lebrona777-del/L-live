# L LIVE — სრული საწყისი პროექტი

## მიზანი
საქართველოს სპორტის ერთიანი LIVE პლატფორმა: ერთი აპი, სადაც ერთიანად ჩანს
საჯაროდ/ოფიციალურად ხელმისაწვდომი ქართული სპორტის LIVE, კალენდარი, შედეგები,
ცხრილები, გუნდები და სპორტსმენები.

გათვალისწინებულია:
- ფეხბურთი
- GAFA / სამოყვარულო ფეხბურთი
- Betlive Master League — მხოლოდ ჩემპიონატის სპორტული მონაცემები
- კალათბურთი
- რაგბი
- ჩოგბურთი
- ძიუდო
- ჭიდაობა
- კრივი
- ჭადრაკი
- სხვა სპორტების დამატების არქიტექტურა

## გაშვება
1. დააყენე Node.js
2. ტერმინალში ამ საქაღალდეში:
   npm install
   npm start
3. გახსენი http://localhost:3000

## ავტომატური მონაცემები
ამ ვერსიაში backend/API და საერთო მონაცემთა მოდელი უკვე არის.
რეალური 24/7 მონაცემებისთვის შემდეგი ნაბიჯია თითოეული ოფიციალური/საჯარო
წყაროს adapter-ის დამატება. წყაროს მიერ გამოქვეყნებული მონაცემი გადადის
საერთო ფორმატში და შემდეგ L LIVE აჩვენებს.

მნიშვნელოვანი: `server.js`-ში არსებული მატჩები დემო მონაცემებია.
ისინი არ უნდა ჩაითვალოს რეალურ LIVE ანგარიშებად.

## API
GET /api/health
GET /api/events
POST /api/events
PATCH /api/events/:id

## წყაროების პრინციპი
ოფიციალური/საჯარო წყარო -> adapter -> საერთო მონაცემთა ბაზა -> L LIVE.
თუ წყარო არ აქვეყნებს კონკრეტულ LIVE მოვლენას, აპი მას არ იგონებს.
